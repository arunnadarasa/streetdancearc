# Plan: Hackathon Checkpoint 3 submission assets

## Goal
Give the user everything needed to complete the Encode Club "Checkpoint 3 Submission" form in one shot: paste-ready submission copy, a code-repo link, and a project image that matches the StreetRail brand.

## Deliverables
1. **Project Name** — `StreetRail` (with optional continuity note: formerly DanceMove Tokens).
2. **Short one-liner** — ~50 words for any short-description field.
3. **Submission Details** — detailed explanation of work, process, and key achievements, tuned for the Agentic Economy Track.
4. **Link to Code** — the published GitHub repo URL (or a placeholder if not yet public).
5. **Project Image** — generate a premium StreetRail hero/thumbnail in the "Midnight Indigo" visual style, sized as a safe 1:1 square (1024×1024) so it works whether the form crops to square or rectangle.

## Visual direction for the image
- Mood: sleek, premium, street-dance culture meets on-chain finance.
- Palette: deep indigo/navy background, electric violet and cyan accents, subtle aurora gradients.
- Subject: a stylized cypher of street-dancers / streetwear mannequins arranged like a rail, with glowing USDC/EURC/cirBTC token icons and the StreetRail wordmark feel.
- Style: photorealistic 3D render or cinematic editorial product shot, not cartoonish.
- No tiny text; image must read as a thumbnail.

## Steps
1. Pull the current repo URL from project metadata / ask the user if it is not known.
2. Draft the submission copy in `/mnt/documents/StreetRail-Submission-Copy.md`.
3. Generate the project image with the agent image tool and save to `/mnt/documents/streetrail-project-image.png`.
4. Verify the image visually (no clipping, strong thumbnail readability).
5. Present the copy inline and the image as a downloadable artifact.
